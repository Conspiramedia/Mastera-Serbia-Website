# Замена телефона на сербский номер

Что осталось сделать после покупки сим-карты в Сербии — и как это сделать
одной командой.

## Коротко

```bash
bash scripts/set-phone.sh +381XXXXXXXXX
```

Скрипт сам найдёт и заменит номер во всех формах, уберёт TODO из
`script.js` и проверит, что ничего не сломалось.

---

## Почему номер до сих пор грузинский

Сайт — форк грузинского проекта (Тбилиси → Сербия). Почти всё локализовано,
но телефон **+995 557 645 196** остался: своей сим-карты в Сербии нет,
а выдумывать номер нельзя — он стоит в шапке всех страниц, в кнопке
WhatsApp и в микроразметке. По выдуманному номеру будут звонить живые
клиенты, и они попадут в никуда (или чужому человеку).

Поэтому замена отложена до появления реального `+381`.

## Где именно встречается номер

**451 вхождение в 118 файлах**, в четырёх формах:

| Форма | Где | Сколько |
|---|---|---|
| `tel:+995557645196` | ссылка «позвонить» в шапке | 117 |
| `// +995 557 645 196` | видимый текст в шапке | 117 |
| `wa.me/995557645196` | плавающая кнопка WhatsApp | 118 |
| `"telephone": "+995557645196"` | JSON-LD, schema.org | 99 |

Строка шапки содержит сразу две формы (в `href` и в тексте ссылки),
поэтому вхождений больше, чем строк.

Отдельно — `script.js`: там кнопка WhatsApp собирается на лету, номер
зашит в коде рядом с TODO-комментарием.

## Как заменить

### 1. Посмотреть, что будет затронуто (ничего не меняет)

```bash
bash scripts/set-phone.sh --dry-run +381601234567
```

### 2. Заменить

```bash
bash scripts/set-phone.sh +381601234567
```

Номер принимается в любом виде — `+381601234567`, `381 60 123 4567`,
`060/123-4567`. Скрипт приведёт его к формату сайта (`+381 60 123 4567`)
по тому же правилу, что и `formatSerbianPhone()` в `script.js`, чтобы
шапка и поле ввода показывали номер одинаково.

Скрипт откажется работать, если после `+381` не 8–10 цифр — это та же
проверка, что и `PHONE_PATTERN` в `script.js`.

### 3. Проверить глазами

```bash
npx serve . -l 3000
```

Открыть любую страницу и убедиться, что:
- в шапке правильный номер и он кликается (`tel:`);
- плавающая кнопка WhatsApp ведёт на новый номер;
- в консоли браузера чисто.

### 4. Выложить

`main` — это продакшен (GitHub Pages собирается из него):

```bash
git add -A
git commit -m "Телефон: сербский номер +381 XX XXX XXXX"
git push origin main
```

## Что скрипт проверяет сам

После замены он прогоняет три проверки и печатает результат:

1. **Старого номера не осталось** — ни слитного, ни с пробелами.
2. **JSON-LD валиден** — все 117 блоков `application/ld+json` парсятся.
   Это важно: номер лежит внутри разметки, и сломанная кавычка убила бы
   микроразметку страницы для поисковиков.
3. **`script.js` не сломан** — через `node --check`, если node установлен.

Запускать повторно безопасно: если старого номера уже нет, скрипт
сообщит об этом и ничего не тронет.

## Смежное

- Номер WhatsApp и номер в шапке — **один и тот же**. Если для WhatsApp
  будет отдельный номер, скрипт не подойдёт: он меняет всё разом.
  Тогда правьте `wa.me/` отдельно.
- Телефон в **боте** (Telegram) живёт не здесь, а в репозитории бота —
  этот скрипт его не трогает.
- Не путать с `scripts/go-live.sh` — тот снимает `noindex` перед
  запуском сайта. Это независимые шаги: телефон можно поменять
  хоть до, хоть после открытия индексации.
